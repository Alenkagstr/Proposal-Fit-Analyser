# Карта проекта

Браузер → Python-сервер → извлечение требований и опыта → сопоставление → проверки → справка.

| Файл | Назначение |
| --- | --- |
| `static/index.html` | Тексты и структура страницы |
| `static/style.css` | Оформление |
| `static/app.js` | Кнопки и запросы к серверу |
| `app.py` | API, процесс анализа и экспорт |
| `documents.py` | Извлечение ссылок и чтение XLSX |
| `ai_service.py` | Подключение AI и проверка JSON |
| `notebook_core.py` | Промпты и аналитические функции из ноутбука |
| `dev.py` | Запуск разработки и обновление |
| `tests/` | Автоматические проверки |

В AI-режиме требования извлекаются из Proposal, опыт — из CV и заявки. Модель сопоставляет их; Python проверяет формат, ID доказательств, правила статусов и дословные цитаты. Справку оценивает эксперт.

Локальный режим ищет совпадения слов, не оценивает смысл. Внешние страницы по ссылкам не загружаются. Обучение собственной модели, пакетный анализ кандидатов и измерение качества на экспертной разметке пока не реализованы.

Начните с изменения текста в HTML и цвета `--blue` в CSS. Запуск: `py -3 dev.py`. Сохраните файл, обновите браузер. Не добавляйте ключи и документы кандидатов в Git.
